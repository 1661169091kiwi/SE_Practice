# 体育赛事数据采集系统 - 后端 API 文档

## 1. 接口概述

本文档描述了体育赛事数据采集系统的后端 API 接口规范。该系统支持多种运动类型的数据采集，包括足球、篮球、羽毛球、排球和水上运动。系统主要提供以下核心功能：

- 用户登录与认证
- 获取首页信息（待采集赛事列表、统计数据等）
- 获取指定赛事的基础信息
- 提交采集的赛事数据到服务器

## 2. 基础 URL

系统采用 RESTful API 设计风格，所有采集员相关接口均以 `/api/collector` 为前缀，并根据不同运动类型提供分类接口：

```
# 通用格式
/api/collector/{sportType}/...

# 具体运动类型示例
足球: /api/collector/football/...
篮球: /api/collector/basketball/...
羽毛球: /api/collector/badminton/...
排球: /api/collector/volleyball/...
水上运动: /api/collector/water/...
```

## 3. 认证机制

系统采用 token-based 认证机制，采集员在登录后获得认证令牌，后续请求需在请求头中携带该令牌：

```
Authorization: Bearer {token}
```

## 4. 接口详情

### 4.1 获取赛事详细数据

- `sportType`：运动类型（football/basketball/badminton/volleyball/water）

```
Authorization: Bearer {token}
```

## 5. 数据模型

### 5.1 赛事信息 (EventInfo)

```typescript
interface EventInfo {
  id: number // 赛事唯一标识
  name: string // 赛事名称
  teamA: string // 队伍A名称
  teamB: string // 队伍B名称
  time: string // 赛事时间 (YYYY-MM-DD HH:MM)
  venue: string // 比赛场地
  sportType: string // 运动类型 (football/basketball/badminton/volleyball/water)
  status: string // 赛事状态 (not_started/in_progress/finished)
}
```

## 6. 错误处理

系统采用统一的错误处理机制，错误响应格式如下：

```json
{
  "code": 400,
  "message": "请求参数错误",
  "detail": "缺少必要的字段: eventId"
}
```

### 常见错误码

| 错误码 | 描述           | 可能原因                   |
| ------ | -------------- | -------------------------- |
| 400    | 请求参数错误   | 缺少必要字段、字段格式错误 |
| 401    | 未授权         | token 无效、过期或未提供   |
| 403    | 禁止访问       | 用户权限不足               |
| 404    | 资源不存在     | 请求的赛事ID不存在         |
| 500    | 服务器内部错误 | 服务器处理请求时发生错误   |

## 7. 前端集成示例

```javascript
// 基础API路径
const BASE_API_URL = '/api'

// 动态获取API路径
const getApiPathBySportType = (sportType, endpoint) => {
  return `${BASE_API_URL}/collector/${sportType}/${endpoint}`
}

// 获取认证令牌
const getAuthToken = () => {
  return localStorage.getItem('token')
}

// 设置认证令牌
const setAuthToken = (token) => {
  localStorage.setItem('token', token)
}

// 移除认证令牌
const removeAuthToken = () => {
  localStorage.removeItem('token')
}

// 获取用户信息
const getUserInfo = () => {
  const userInfoStr = localStorage.getItem('userInfo')
  return userInfoStr ? JSON.parse(userInfoStr) : null
}

// 设置用户信息
const setUserInfo = (userInfo) => {
  localStorage.setItem('userInfo', JSON.stringify(userInfo))
}

// 移除用户信息
const removeUserInfo = () => {
  localStorage.removeItem('userInfo')
}

// 用户登录
const login = async (studentId, password) => {
  try {
    const response = await fetch(`${BASE_API_URL}/collector/auth/login`, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
      },
      body: JSON.stringify({
        studentId,
        password,
      }),
    })

    if (!response.ok) {
      const errorData = await response.json()
      throw new Error(errorData.message || '登录失败')
    }

    const loginResult = await response.json()

    // 保存认证信息到本地存储
    setAuthToken(loginResult.token)
    setUserInfo(loginResult.userInfo)

    return loginResult
  } catch (error) {
    console.error('登录失败:', error)
    throw error
  }
}

// 获取首页信息
const fetchDashboardData = async () => {
  try {
    const response = await fetch(`${BASE_API_URL}/collector/dashboard`, {
      method: 'GET',
      headers: {
        Authorization: `Bearer ${getAuthToken()}`,
      },
    })

    if (!response.ok) {
      const errorData = await response.json()
      throw new Error(errorData.message || '获取首页信息失败')
    }

    return await response.json()
  } catch (error) {
    console.error('获取首页信息失败:', error)
    throw error
  }
}

// 获取赛事数据
const fetchEventData = async (sportType, eventId) => {
  try {
    const apiPath = getApiPathBySportType(sportType, `events/${eventId}`)
    const response = await fetch(apiPath, {
      method: 'GET',
      headers: {
        Authorization: `Bearer ${getAuthToken()}`,
      },
    })

    if (!response.ok) {
      const errorData = await response.json()
      throw new Error(errorData.message || '获取赛事数据失败')
    }

    return await response.json()
  } catch (error) {
    console.error('获取赛事数据失败:', error)
    throw error
  }
}

// 提交赛事数据到服务器
const submitEventDataToServer = async (sportType, eventId, eventInfo, sportData) => {
  try {
    const apiPath = getApiPathBySportType(sportType, `events/${eventId}/submit`)
    const response = await fetch(apiPath, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        Authorization: `Bearer ${getAuthToken()}`,
      },
      body: JSON.stringify({
        eventId,
        eventInfo,
        sportData,
      }),
    })

    if (!response.ok) {
      const errorData = await response.json()
      throw new Error(errorData.message || '提交数据失败')
    }

    return await response.json()
  } catch (error) {
    console.error('提交数据到服务器失败:', error)
    throw error
  }
}
```
